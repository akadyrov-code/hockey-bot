# Утренняя задача: шортсы с голами Данила

Ты делаешь короткие вертикальные ролики с голами **Данила Нигматуллина** (#90, МХК «Кристалл»)
для семейного Telegram-канала. Ролик вырезается из записи трансляции матча (она открыта на
сайте лиги, видео лежит в VK). Бот на GitHub публикует готовый файл из `content/video/`.

Главная трудность — найти в двухчасовой записи секунду, когда забит гол. В протоколе есть
игровое время гола, а в углу трансляции — табло со счётом и часами. Ты смотришь на кадры
и по часам на табло находишь нужное место.

## Шаги

1. `git pull --rebase`. Если нет пакетов — `.venv/bin/pip install -r requirements-extras.txt`.
2. `.venv/bin/python -m bot.shorts pending` — список голов, для которых ещё нет ролика.
   Пустой список (`[]`) — работа закончена, ничего не коммить.
   У каждого гола есть: `match_id`, `n` (номер гола Данила в матче), `period`, `time`
   (время от начала матча), `score_after`, `clock_counting_up` и `clock_counting_down`
   (что показывают часы на табло в момент гола, если они идут вперёд или назад).
   Если `video` пустое — записи нет, этот гол пропусти.
3. Для каждого гола найди секунду записи (см. «Как найти гол»), затем:
   - `.venv/bin/python -m bot.shorts cut <match_id> <n> --goal-at <секунда>`
     Команда соберёт ролик (9 секунд до гола и 16 после) и лист кадров для проверки.
   - Открой лист кадров (Read) и проверь ролик (см. «Проверка»). Если гол не попал в кадр —
     поправь `--goal-at` и собери заново. Не больше трёх попыток на гол.
   - `.venv/bin/python -m bot.shorts add <match_id> <n>` — поставить ролик в очередь бота.
4. `.venv/bin/python -m bot.shorts prune` — убрать из `content/video/` ролики, которых уже
   нет в очереди (очередь чистит вечерняя задача: элементы старше 7 дней).
5. `.venv/bin/python -m bot.extras --validate`, затем
   `git add content && git commit -m "shorts: <дата>" && git push`
   (если push отклонён — `git pull --rebase` и снова `git push`).

## Как найти гол

1. Обзор записи: `.venv/bin/python -m bot.shorts sheet <match_id> --every 300`.
   Команда печатает путь к картинке — открой её (Read). На ней угол кадра с табло каждые
   5 минут записи, над каждым кадром подпись `t=<секунда записи>`.
   По ней пойми:
   - где на записи идёт нужный период (на табло: `1ST`/`2ND`/`3RD`, «1 период», «2 пер»…);
   - в какую сторону идут часы: если с ростом `t` время на табло уменьшается — назад
     (тогда гол при `clock_counting_down`), если растёт — вперёд (`clock_counting_up`);
   - между какими двумя кадрами находится гол (по часам и по счёту: после гола счёт
     становится `score_after`).
   Если табло в углу не видно — добавь `--full` (весь кадр) и посмотри, где оно.
2. Сузь поиск: `sheet <match_id> --from A --to B --every 20`, потом `--every 5`
   (не больше 40 кадров за раз). Ищи место, где часы доходят до времени гола.
   В момент гола игру останавливают: **часы замирают на времени гола**, а счёт на табло
   меняется чуть позже (через 10–40 секунд). Значит, секунда гола — это момент, когда часы
   впервые показали время гола.
3. Посчитай секунду: возьми последний кадр, где часы ещё шли, и прибавь к его `t` разницу
   между часами на этом кадре и временем гола. Пример: на кадре `t=1135` часы 15:43, гол при
   15:37 → гол на `1135 + 6 = 1141`. Если между кадром и голом была остановка игры (часы на
   двух соседних кадрах одинаковые, а потом снова идут) — бери кадр после остановки.
4. В последнюю минуту периода табло показывает секунды с десятыми: `30.4` — это 00:30.
   Секунды на табло и в протоколе могут расходиться на 1–2 — это нормально.

## Проверка ролика

На листе кадров из `cut` (кадр каждые 2,5 секунды) должно быть видно:
- до гола идёт игра, часы на табло идут;
- примерно на 8–12-й секунде — гол (шайба в воротах, игроки «Кристалла» поднимают руки)
  и часы замирают на времени гола;
- после гола — празднование, желательно с Данилом (#90) в кадре.

Если гол в самом начале или в конце ролика — сдвинь `--goal-at`. Если празднование обрезано —
добавь `--after 20`. Если атака началась раньше — `--before 12`. Ролик длиннее 35 секунд не делай.

## Правила

- Не уверен, что в ролике именно этот гол (нет табло, запись обрывается, время не сходится) —
  **не публикуй**, пропусти гол и напиши об этом в отчёте. Лучше без ролика, чем не тот момент.
- Только голы Данила из списка `pending`. Ничего не дорисовывай и не меняй подписи вручную.
- Меняй только папку `content/`. Код бота, `config.json` и `state.json` не трогай.
- Сайт лиги или VK не отвечают — попробуй ещё раз через минуту; если снова нет, остановись.
  Защиту сайтов не обходи.
- В конце напиши одной-двумя строками, какие ролики добавлены и какие голы пропущены.
