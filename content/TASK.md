# Вечерняя задача: викторина и пост на завтра

Ты готовишь дополнения для семейного Telegram-канала про хоккеиста **Данила Нигматуллина**
(#90, нападающий МХК «Кристалл» Саратов, РХЛ, конференция «Восток»). Канал читают его
родные. Бот на GitHub публикует то, что ты положишь в `content/queue.json`, в указанное время.
Это дополнение: статистику, голы и сводки бот присылает сам — не повторяй их.

## Шаги

1. Обнови репозиторий: `git pull --rebase`.
2. Выгрузи свежие факты: `.venv/bin/python -m bot.facts > /tmp/hockey-facts.json` и прочитай файл.
   Если сайт лиги не отвечает — попробуй ещё раз через минуту; если снова нет, остановись
   и ничего не публикуй.
3. Открой `content/queue.json`. Удали элементы с `publish_at` старше 7 дней.
   Если на завтра уже есть элементы — ничего не добавляй (задача могла запуститься дважды).
4. Добавь на **завтра** (по Москве) два элемента:
   - **викторину** (`type: "quiz"`) на 11:00;
   - **пост** (`type: "text"`) на 19:00.
   Если завтра у «Кристалла» матч (`upcoming_matches`), сдвинь время, чтобы не попасть
   в интервал от 2 часов до начала до 3 часов после начала, а пост сделай превью этой игры.
5. Проверь: `.venv/bin/python -m bot.extras --validate`. Исправь ошибки, если есть.
6. Закоммить и отправь: `git add content/queue.json && git commit -m "content: <дата>" && git push`.
   Если push отклонён — `git pull --rebase` и снова `git push`.

## Формат элементов

```json
{"id": "2026-11-06-quiz", "type": "quiz", "publish_at": "2026-11-06T11:00:00+03:00",
 "question": "…?", "options": ["…", "…", "…", "…"], "correct": 1,
 "explanation": "…"}

{"id": "2026-11-06-post", "type": "text", "publish_at": "2026-11-06T19:00:00+03:00",
 "title": "✨ …", "text": "…"}
```

- `id` — уникальный: дата + тип.
- `correct` — номер правильного варианта **с нуля**.
- Лимиты Telegram: вопрос ≤ 300 символов, вариант ≤ 100, 2–10 вариантов, пояснение ≤ 200,
  пост ≤ 3500. Текст — обычный, без HTML и Markdown; эмодзи можно.

## Правила содержания

- **Только факты из `/tmp/hockey-facts.json`.** Никаких придуманных чисел, событий, цитат.
  Если чего-то в файле нет — не пиши об этом. Общие факты о хоккее — только общеизвестные.
- Правильный ответ викторины должен однозначно следовать из файла; неверные варианты —
  правдоподобные, но неверные. Перемешивай позицию правильного ответа.
- Темы чередуй, не повторяйся с последними 7 днями в очереди: статистика Данила
  (голы, передачи, броски, время на льду, вбрасывания, +/-), его место в команде и конференции,
  таблица «Востока», лидеры конференции, ближайший соперник, сравнение с прошлыми играми,
  забавные совпадения в цифрах, лёгкие вопросы о правилах хоккея.
- Пост: 3–6 предложений, тёплый семейный тон, можно с лёгким юмором; превью — что за соперник,
  где он в таблице, на что смотреть. Без негатива о Даниле и других игроках.
- Пиши по-русски.
