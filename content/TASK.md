# Вечерняя задача: дополнения на завтра

Ты готовишь дополнения для семейного Telegram-канала про хоккеиста **Данила Нигматуллина**
(#90, нападающий МХК «Кристалл» Саратов, РХЛ, конференция «Восток»). Канал читают его
родные, в том числе те, кто в хоккее разбирается не очень. Бот на GitHub публикует то,
что ты положишь в `content/queue.json`, в указанное время. Это дополнение: статистику,
голы, итоги, сводки и лидеров бот присылает сам — не повторяй их.

## Шаги

1. Обнови репозиторий: `git pull --rebase`.
2. Выгрузи свежие факты: `.venv/bin/python -m bot.facts > /tmp/hockey-facts.json` и прочитай файл.
   Если сайт лиги не отвечает — попробуй ещё раз через минуту; если снова нет, остановись
   и ничего не публикуй.
3. Открой `content/queue.json`. Удали элементы с `publish_at` старше 7 дней (и их картинки
   из `content/img/`). Посмотри, что было за последние 7 дней, чтобы не повторяться.
4. На **завтра** (по Москве) нужны два слота:
   - **утро, 11:00 — викторина** (`quiz`);
   - **вечер, 19:00 — один из форматов ниже** (по очереди, см. «Ротация»).
   Если слот на завтра уже занят (задача могла запуститься дважды) — не трогай его.
   Если оба заняты — заверши работу.
   Если завтра у «Кристалла» матч (`upcoming_matches`), не ставь ничего в интервал от 2 часов
   до начала до 4 часов после начала — сдвинь слот раньше или позже.
5. Проверь: `.venv/bin/python -m bot.extras --validate`. Исправь ошибки, если есть.
6. Закоммить и отправь: `git add content && git commit -m "content: <дата>" && git push`.
   Если push отклонён — `git pull --rebase` и снова `git push`.

## Вечерние форматы

- **🔮 Прогноз** (`poll`) — обязательно, если завтра или послезавтра матч «Кристалла» и прогноза
  на эту игру ещё не было. Ставь за день до матча (или утром в день матча, если матч вечером).
  Вопросы вроде «Сколько очков наберёт Данил против <соперник>?» (0 / 1 / 2 / 3 и больше) или
  «Чем закончится матч?». Варианты — ровные, без правильного ответа.
- **🆚 Знакомимся с соперником** (`text`) — перед серией с новым соперником: где он в таблице,
  форма за последние 5 игр, его лучшие бомбардиры из лидеров конференции, как сыграли
  прошлые очные матчи, если они есть в `player_games_this_season`.
- **📈 График** (`photo`) — раз в неделю. Нарисуй картинку matplotlib из `.venv/bin/python`
  (если matplotlib не установлен — `.venv/bin/pip install -r requirements-extras.txt`).
  Идеи: очки Данила по играм и нарастающим итогом; голы/передачи по играм; место «Кристалла»
  в «Востоке» среди соперников (горизонтальные столбцы очков с чертой плей-офф).
  Требования: 1200×800, PNG до 1 МБ, крупные подписи по-русски, понятный заголовок,
  Данил/«Кристалл» выделены цветом. Сохрани в `content/img/<id>.png`.
- **📖 Хоккейный словарик** (`text`) — простое объяснение одного термина на примере из
  статистики Данила: +/-, вбрасывание, большинство/меньшинство, буллиты, хет-трик, ассистент,
  «чистый» гол, плей-офф и черта плей-офф, проценты реализации бросков.
- **✨ Факт дня** (`text`) — интересное в цифрах: рекорды и серии Данила, совпадения,
  сравнения с партнёрами по команде и лидерами конференции.

### Ротация

Если нет обязательного прогноза — выбери формат, которого дольше всего не было за 7 дней;
график — не чаще раза в неделю, лучше по выходным или после игровой серии.

## Формат элементов

```json
{"id": "2026-11-06-quiz", "type": "quiz", "publish_at": "2026-11-06T11:00:00+03:00",
 "question": "…?", "options": ["…", "…", "…", "…"], "correct": 1, "explanation": "…"}

{"id": "2026-11-06-poll", "type": "poll", "publish_at": "2026-11-06T19:00:00+03:00",
 "question": "🔮 …?", "options": ["…", "…", "…"]}

{"id": "2026-11-06-post", "type": "text", "publish_at": "2026-11-06T19:00:00+03:00",
 "title": "✨ …", "text": "…"}

{"id": "2026-11-06-chart", "type": "photo", "publish_at": "2026-11-06T19:00:00+03:00",
 "image": "content/img/2026-11-06-chart.png", "caption": "📈 …"}
```

- `id` — уникальный: дата + тип.
- `correct` — номер правильного варианта **с нуля**.
- Лимиты Telegram: вопрос ≤ 300 символов, вариант ≤ 100, 2–10 вариантов, пояснение ≤ 200,
  подпись к картинке ≤ 1000, пост ≤ 3500. Текст — обычный, без HTML и Markdown; эмодзи можно.

## Правила содержания

- **Только факты из `/tmp/hockey-facts.json`.** Никаких придуманных чисел, событий, цитат.
  Если чего-то в файле нет — не пиши об этом. Общие факты о хоккее — только общеизвестные.
- Викторина: правильный ответ однозначно следует из файла; неверные варианты правдоподобны.
  Перемешивай позицию правильного ответа. Темы чередуй: статистика Данила (голы, передачи,
  броски, время на льду, вбрасывания, +/-), его место в команде и конференции, таблица
  «Востока», лидеры конференции, ближайший соперник, лёгкие вопросы о правилах хоккея.
- Тексты: 3–6 предложений, тёплый семейный тон, можно с лёгким юмором.
  Без негатива о Даниле и других игроках.
- Пиши по-русски.
