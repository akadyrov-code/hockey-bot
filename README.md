# Хоккейный бот: Данил Нигматуллин #90, МХК «Кристалл»

Бот присылает в Telegram-канал всё про игры Данила. Данные берёт с сайта
РХЛ ([rhl.fhr.ru](https://rhl.fhr.ru)) и из группы ВК «Кристалла». Работает
бесплатно на GitHub Actions: компьютер включённым держать не нужно.

Бот работает «сменами» примерно по 5,5 часа: внутри смены проверяет всё каждую минуту,
а в конце сам запускает следующую смену. Расписание GitHub (два раза в час) — запасной
вариант на случай, если цепочка оборвётся.

## Что приходит в канал

| Когда | Что |
|---|---|
| За ~1 час до матча бот начинает следить | 🔴 ссылка на прямую трансляцию, как только она появится |
| Во время игры (проверка раз в минуту) | 🏒 начало матча, 🚨 голы по изменению счёта, ⏸ перерывы со счётом. Авторы голов, передачи и удаления Данила — как только лига внесёт их в протокол (обычно после матча: во время игры сайт показывает только счёт) |
| После финальной сирены | 🏁 сразу счёт; затем 🖼 картинка-итог (счёт, строка Данила, вехи и рекорды: дубль, хет-трик, круглые цифры, серии) и подробный итог (голы и удаления «Кристалла», статистика Данила и нападающих за матч и сезон, запись, протокол) — когда лига заполнит протокол: обычно ближе к ночи (бот ждёт до 36 часов). С 23:00 до 8:00 сообщения приходят без звука (`quiet_hours` в config.json) |
| Через 30–60 мин после матча | 📋 сводка после матча (когда лига обновит статистику и таблицу) |
| По будням в 12:00 мск, только накануне и в день матча | ☀️ статистика Данила за сезон, последняя игра, место в конференции, ближайший матч (`daily_only_near_match` в config.json) |
| Утром после матча, если Данил забил | 🎬 шортс с голом — вертикальный ролик из записи трансляции (см. ниже) |
| Четверг, 20:00 мск | 🏆 бомбардиры, снайперы и ассистенты «Кристалла» и конференции, место Данила |
| Понедельник, 10:00 мск | 📊 таблица конференции «Восток» с комментарием и календарь на неделю |
| Когда выходит обзор на сайте лиги | 📰 цитата о Даниле и ссылка (или новость о «Кристалле» по заголовку) |
| После матчей (если подключён ВК) | 📸 новые фотоальбомы (с ключом Claude — только фото с №90); 📰 посты, где упоминается Данил |

Время матчей указывается по Москве и по Уфе.

## Дополнения от Claude (вечерние посты)

Необязательная часть. Каждый вечер задача по расписанию в приложении Claude на Mac
(на подписке) выгружает свежие факты (`python -m bot.facts`), готовит на завтра
вечерний пост (прогноз, соперник, график, словарик, факт дня) и кладёт его в `content/queue.json` по инструкции из `content/TASK.md`.
Бот публикует их в указанное время. Mac выключен — в этот день дополнений нет,
всё остальное работает как обычно.

## Шортсы с голами Данила

Тоже необязательная часть и тоже задача в приложении Claude на Mac (утром, по инструкции из
`content/SHORTS.md`). Если Данил забил, Claude по табло в кадрах трансляции находит секунду
гола, вырезает 25 секунд (`python -m bot.shorts`), делает вертикальный ролик с подписями и
кладёт его в `content/video/`. Бот публикует ролик из очереди. Нужны пакеты из
`requirements-extras.txt`. Ролики хранятся в репозитории неделю (~6 МБ каждый).

Проверка бота без Telegram: `python tests/sim_match.py` — имитация игрового дня.

## Настройка (один раз)

### 1. Секреты репозитория
**Settings → Secrets and variables → Actions → New repository secret**

| Имя | Что вставить | Обязательно |
|---|---|---|
| `TG_TOKEN` | токен бота от @BotFather | да |
| `TG_CHAT_ID` | id канала, если бот не найдёт его сам (вида `-100…`) | нет |
| `VK_TOKEN` | сервисный ключ приложения ВК (для постов и фото) | нет |
| `ANTHROPIC_API_KEY` | ключ Claude API (для распознавания №90 на фото) | нет |

### 2. Первый запуск
1. Напиши любое сообщение в канале, чтобы бот его «увидел».
2. **Actions → hockey-bot → Run workflow**.
3. В канал придут приветствие, утренняя сводка и таблица. Дальше бот работает сам.

### 3. ВКонтакте (по желанию)
1. Открой [id.vk.com/about/business](https://id.vk.com/about/business) и создай приложение (тип «Web»).
2. В настройках приложения скопируй **Сервисный ключ доступа**.
3. Добавь его в секрет `VK_TOKEN`.

## Настройки — `config.json`

- `daily_hour`, `daily_weekdays` (0 = понедельник), `weekly_weekday`, `weekly_hour` — когда слать сводки.
- `extra_timezones` — дополнительные часовые пояса (сейчас Уфа).
- `vk.groups` — группы ВК; `vk.keywords` — какие посты пересылать; `vk.all_posts: true` — пересылать все посты.
- `photos.model` — модель Claude для фото; `photos.jersey_hint` — подсказка про цвет формы
  (например, «У Кристалла дома синяя форма, в гостях белая»).

## Если что-то сломалось

- Логи: **Actions → последний запуск → run**.
- Если сайт лиги поменяет вёрстку, чинить нужно `bot/rhl.py`.
- GitHub отключает расписание в репозитории, где 60 дней не было активности. Бот сам
  коммитит `state.json`, но если придёт письмо об отключении, нажми **Enable workflow**.

Локальная проверка без отправки в Telegram:

```bash
pip install -r requirements.txt
DRY_RUN=1 python -m bot.main
```
